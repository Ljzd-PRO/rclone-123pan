# 123Pan backend

The remote type is `123pan`, with flags prefixed by `--pan123-`.
Only personal-account username/password authentication is in scope.

The backend must connect directly to 123Pan. It does not use OpenList's public
token service, which belongs to the separate `123_open` driver.

The read-side implementation advertises MD5, preserves server update time for
display, and reports `fs.ModTimeNotSupported` because the web API cannot set it.
Every directory is read in pages of 100 using `file_id desc`; a result is
returned only after `Total`, unique IDs, names, and the termination marker all
agree. A failed consistency round is discarded in full and retried at most
three times.

Decoded names that collide, or any two entries with the same visible name and
different IDs, fail closed as a path-ambiguity error. No arbitrary object is
selected. Custom roots are resolved through ID-backed directory traversal and
the resolved root must be listable before initialization succeeds.

Downloads request fresh metadata, strictly unwrap optional Base64 parameters,
resolve either a 302 or JSON redirect without automatic redirect following,
and use a separate unauthenticated data-plane client. Range, seek, and suffix
requests are normalized through rclone and the returned status,
`Content-Range`, declared length, and actual stream length are checked. A final
CDN 403 refreshes the signed URL once; a partially read body is never resumed
silently.

Uploads first request MD5 from the source. A valid supplied MD5 and known size
allow a rapid-upload request without reading the body. Otherwise the source is
read once: inputs up to `hash_memory_limit` (10 MiB by default) are kept in
memory and larger or unknown-size inputs are securely spooled under
`--temp-dir`, then rewound with accounting restored. Declared size, actual size,
and MD5 must agree. `Reuse=true` remains only a candidate success until a fresh
listing proves ID, name, parent, size, MD5, and object type; a rapid hit reads
zero body bytes.

Mutation instructions will be added alongside those milestones.
