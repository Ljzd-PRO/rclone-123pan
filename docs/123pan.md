# 123Pan backend

The future remote type is `123pan`, with flags prefixed by `--pan123-`.
Only personal-account username/password authentication is in scope.

The backend must connect directly to 123Pan. It does not use OpenList's public
token service, which belongs to the separate `123_open` driver.

The backend is currently a buildable registration scaffold. Functional setup
instructions will be added alongside each implemented capability.
